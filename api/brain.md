# HOW TO READ THIS FILE

This is the whole knowledge base for Ask Rish. It is sent to the model as
CONTEXT on every request, and the system prompt forbids answering from
anything else: if a fact is not written here, the bot says "That's not in my
notes. Email me at theardentguy@gmail.com and I'll answer properly."

So an empty section is not a gap in the bot, it is a working refusal. Fill one
in and the bot starts answering that topic. Nothing in this file was invented:
every claim below is copied from the live site or the case studies. The four
sections marked NOT WRITTEN YET are his to write, and until he does the bot
correctly declines those questions.

Keep it under about 30,000 words and it can stay one file with no retrieval
step (spec 11.2).
